# dev-cut-TH

🖱️ โปรแกรมกดใช้ (Windows) — ติดตั้งปุ่มเดียว, แชทในตัว, ลากคลิปมาวาง, ปุ่มงานด่วน TikTok/YouTube
✂️ ตัดช่วงเงียบอัตโนมัติ จากขอบคำจริง (ไม่กินคำ) — non-destructive แก้ต่อใน CapCut ได้เสมอ
💬 ซับไทย + karaoke ไฮไลต์คำ ซิงก์ตามเสียงจริง — เปิดอัตโนมัติสำหรับคลิปแนวตั้ง
🆓 export ฟรี ไม่ติด CapCut Pro (ปิดฟีเจอร์ Pro เป็นค่าเริ่มต้น)
🎨 หน้าเลือกเห็นภาพจริง — สไตล์ซับ / กราฟิก (title card, แถบชื่อ, end card) / เสียงประกอบ 18 เสียง (ฟังก่อนเลือกได้)
🇹🇭 ถอดเสียงไทยในเครื่อง ด้วยโมเดล Thonburian (จูนเฉพาะไทย, ออฟไลน์, ไม่มีโควตา)
🎵 แยกเสียงพูดจากเพลง อัตโนมัติเมื่อเจอ BGM (คลิปอนิเมะ/เกม/ไฮไลต์ซับแม่นขึ้น)
🎬 ทำอะไรได้บ้าง
ตัดช่วงเงียบ · ถอดเสียง/ทำซับไทย · karaoke · เลือกสไตล์ซับ · ทำกราฟิก (title/แถบชื่อ/end card) · ไดคัทลบพื้นหลัง · หา b-roll/รูปฟรี · เสียงประกอบ (SFX) · เพลงพื้นหลัง+หรี่เสียงอัตโนมัติ · สรุปงานส่งต่อ editor

เบื้องหลังเป็น 9 skills (transcribe · analyze · clean-cut · capcut · style · cutout · gen-assets · find-assets · handoff) ที่ AI เรียกใช้อัตโนมัติตามที่คุณสั่ง

📋 สิ่งที่ต้องมี — อ่านก่อน (สำคัญ)
CapCut Desktop (Windows/macOS) — ฟรี
บัญชี Claude ⚠️ — "สมอง" ของโปรแกรมคือ Claude Code ที่คุณล็อกอินด้วยบัญชีตัวเอง → ต้องมี Claude (Pro/Max) หรือ API ของ Anthropic ซึ่งจ่ายแยกต่างหาก (โปรแกรมนี้ฟรี แต่ Claude คุณจ่าย Anthropic เอง)
Windows สำหรับตัวโปรแกรม GUI (ตัว kit ใช้บน mac ผ่าน Claude Code ตรง ๆ ได้ แต่ยังไม่มีหน้าโปรแกรม)
"ฟรี" หมายถึงอะไร: ตัวโปรแกรม + การถอดเสียงไทย (ในเครื่อง) ฟรีจริง ไม่มีโควตา — แต่ยังต้องมีบัญชี Claude (ค่าใช้จ่ายฝั่ง Anthropic) เพราะ AI ที่สั่งงานคือ Claude

⬇️ ติดตั้ง — ดับเบิลคลิก Dev-Cut.vbs
เปิดโปรแกรม → กดปุ่ม ⚙ ติดตั้งครั้งแรก ปุ่มเดียว ระบบไล่ลงให้ครบ (Python, ffmpeg, ไลบรารี, ฟอนต์ LINE Seed, โมเดลถอดเสียง ~1.5GB, Claude Code) รายงานความคืบหน้าในแชท จากนั้นกด 🔗 เชื่อม Claude ล็อกอินครั้งเดียว → พร้อมใช้

ติดตั้งแบบกดเอง (มือโปร)
▶️ เริ่มใช้งาน
เปิดโปรแกรม → ลากคลิปมาวาง → กดปุ่มงานด่วน (ตัด+ซับ ลง TikTok / ลง YouTube) หรือพิมพ์สั่งเอง เช่น:

"ตัดช่วงเงียบคลิปนี้ ใส่ซับไทย ลง TikTok"
"ใส่ซับไทยอย่างเดียว ไม่ต้องตัด แนวตั้ง"
กด ⓘ ฟีเจอร์ เพื่อดูทุกอย่างที่ทำได้ (มีหน้าเลือกสไตล์/กราฟิก/เสียงแบบเห็นภาพ)
ผลลัพธ์เป็น rough cut ใน CapCut ที่คุณรีวิว/ลากแก้ต่อได้เสมอ — ไฟล์ต้นฉบับไม่ถูกแตะ

⚠️ ข้อจำกัด (พูดตรง ๆ)
ต้องรีวิวซับก่อน export เสมอ — ASR ไทยยังผิดคำได้ โดยเฉพาะคลิปพูดเร็ว/มีเพลงดัง/ชื่อเฉพาะ (มีปุ่มแก้คำทั้งไฟล์ช่วย)
ไม่ใช่ปุ่มวิเศษ — เป็นตัวช่วยทำงานน่าเบื่อ (ตัด/ถอด/ซิงก์/แต่ง) ให้เร็วขึ้น ไม่ได้ตัดจบแทนคุณ
ถอดเสียงบน CPU ช้าตามความยาวคลิป (โหมดแม่นสูงยิ่งช้า) — การ์ดจอ AMD ไม่ช่วยเร่ง (รองรับแค่ NVIDIA)
ตัวโปรแกรม GUI เป็น Windows-only
❓ คำถามพบบ่อย
ถอดเสียงต้องต่อเน็ต/เสียเงินไหม? ตัวถอดเสียงไทยอยู่ในเครื่อง ออฟไลน์ ฟรี ไม่มีโควตา (แต่การสั่งงานผ่าน Claude ต้องมีบัญชี Claude)

ทำไมต้องมีบัญชี Claude? เพราะ AI ที่ตีความคำสั่งไทยแล้วเรียกเครื่องมือให้คือ Claude Code — โปรแกรมนี้เป็นตัวห่อ/ตัวจัดการรอบ ๆ

ไฟล์ต้นฉบับจะพังไหม? ไม่มีทาง — ทุกอย่าง non-destructive อยู่ในไฟล์โปรเจกต์ CapCut แยกต่างหาก

มือถือได้ไหม? ไม่ได้ — ต้อง CapCut Desktop
